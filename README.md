# الفتح لتجارة الورق — نظام الحسابات

نسخة أولية قابلة للرفع على GitHub والاستضافة كصفحة ويب. الواجهة عربية وتعمل على الموبايل واللابتوب. تستخدم Supabase لتسجيل الدخول وحفظ البيانات على الإنترنت.

## الموجود في النسخة
- تسجيل دخول بالبريد وكلمة المرور لصاحب الحساب.
- إضافة الموظفين.
- تسجيل التحصيلات والمصروفات وربط كل حركة بالموظف المسؤول.
- ملخص إجمالي التحصيلات والمصروفات وصافي الحركة.
- حساب إجمالي حركة كل موظف.

> هذه نسخة MVP تجريبية وليست نظاماً محاسبياً نهائياً. لا تستخدمها كسجل مالي وحيد قبل الاختبار ومراجعة الإعدادات والنسخ الاحتياطية.

## 1) إنشاء قاعدة البيانات
1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com/).
2. من لوحة المشروع افتح **SQL Editor**.
3. افتح الملف `supabase/schema.sql` وانسخ محتواه إلى SQL Editor ثم اضغط **Run**.
4. من **Authentication → Users** أنشئ مستخدم والدك يدوياً (بريده وكلمة مرور قوية). لا تفعّل التسجيل العام للمستخدمين.

## 2) ربط الموقع بـ Supabase
1. من **Project Settings → API** انسخ **Project URL** و **anon/public key**.
2. افتح `config.js`.
3. استبدل القيمتين `YOUR-PROJECT` و `YOUR_SUPABASE_ANON_PUBLIC_KEY` بالقيم الحقيقية.
4. لا تضع `service_role` أو أي مفتاح سري في ملفات الموقع أو GitHub. مفتاح anon/public مصمم للاستخدام بالمتصفح، والحماية تعتمد على RLS في قاعدة البيانات.

## 3) رفع المشروع إلى GitHub
1. أنشئ مستودعاً جديداً باسم `alfath-paper-accounts`.
2. ارفع كل محتويات هذا المجلد إلى المستودع (لا ترفع ملف ZIP بداخله فقط).
3. من **Settings → Pages** اختر النشر من فرع `main` والمجلد `/ (root)` ثم احفظ.
4. انتظر رابط GitHub Pages. أول فتح قد يستغرق دقائق.

## 4) تجربة الدخول
افتح رابط الموقع، ثم سجّل دخول مستخدم والدك الذي أنشأته في Supabase. أضف موظفاً تجريبياً وسجّل حركة اختبارية.

## تنبيهات مهمة
- بيانات الدخول وقاعدة البيانات موجودة في Supabase، لذلك يلزم الإنترنت لاستخدام المنصة.
- لا تضع كلمات مرور أو مفاتيح سرية في GitHub.
- `config.js` يحتوي فقط على رابط المشروع ومفتاح anon/public. قاعدة البيانات محمية بسياسات Row Level Security في `schema.sql`.
- كل مستخدم يرى سجلاته فقط. النسخة الحالية مصممة لحساب مالك واحد، ولا تحتوي على حسابات دخول منفصلة للموظفين.
- لا يوجد حالياً تعديل أو حذف للحركات، ولا إدارة ديون أو فواتير أو مخزون أو نسخ احتياطي تلقائي.
- فعّل المصادقة الثنائية لحساب Supabase إن أمكن، واستخدم كلمة مرور قوية واحتفظ بها بأمان.
- اختبر العمليات ببيانات وهمية قبل إدخال حسابات الشغل الحقيقية، وراجع الإعدادات مع شخص بالغ موثوق أو مختص تقني.
